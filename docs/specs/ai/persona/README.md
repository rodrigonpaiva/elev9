# Coach Persona Specification

## 1. Overview

`CoachPersonaEngineService` is the deterministic internal layer that translates `UnifiedCoachIntelligence` into communication guidance for the LLM.

It does not generate responses, does not generate prompts, does not call OpenAI, and does not replace the prompt builder. It exists only to decide how the coach should communicate right now.

The output is structured, immutable, and internal-only.

---

## 2. Persona Contract

The persona layer consumes:

- unified coach intelligence
- routing metadata
- runtime metadata
- user profile signals
- fitness profile signals
- personalization settings
- safety decisions

It emits a deterministic persona guidance object containing:

- `tone`
- `verbosity`
- `focus`
- `directiveLevel`
- `empathyLevel`
- `encouragementLevel`
- `technicalDepth`
- `urgency`
- `celebrationLevel`
- `safetyLevel`
- `communicationRules`
- `metadata`

---

## 3. Communication Dimensions

### 3.1 Tone

Allowed values:

- `SUPPORTIVE`
- `DIRECT`
- `ANALYTICAL`
- `CELEBRATORY`
- `CAUTIOUS`
- `CALM`

Tone is derived from objective coaching context, not emotions.

### 3.2 Verbosity

Allowed values:

- `VERY_SHORT`
- `SHORT`
- `NORMAL`
- `DETAILED`

Verbosity is derived from context complexity, safety pressure, and expert density.

### 3.3 Focus

Allowed values:

- `WORKOUT`
- `RECOVERY`
- `NUTRITION`
- `GOALS`
- `CONSISTENCY`
- `PROGRESS`
- `MOTIVATION`
- `SAFETY`

The focus is the primary communication target for the turn.

### 3.4 Directive Level

Allowed values:

- `LOW`
- `MEDIUM`
- `HIGH`

Directive level reflects how strongly the coach should guide the next step.

### 3.5 Empathy Level

Allowed values:

- `LOW`
- `MEDIUM`
- `HIGH`

Empathy level is based on behavior signals only.

### 3.6 Encouragement Level

Allowed values:

- `LOW`
- `MEDIUM`
- `HIGH`

Encouragement level reflects positive reinforcement pressure from objective progress signals.

### 3.7 Technical Depth

Allowed values:

- `BEGINNER`
- `INTERMEDIATE`
- `ADVANCED`

Technical depth is derived from the user fitness profile and behavior signals.

### 3.8 Urgency

Allowed values:

- `NONE`
- `LOW`
- `MEDIUM`
- `HIGH`
- `CRITICAL`

Urgency is elevated only when the underlying coaching state requires immediate attention.

### 3.9 Celebration Level

Allowed values:

- `NONE`
- `LOW`
- `MEDIUM`
- `HIGH`

Celebration level is only used when objective progress signals justify it.

### 3.10 Safety Level

Allowed values:

- `NORMAL`
- `ELEVATED`
- `STRICT`

Safety always overrides stylistic preferences.

---

## 4. Guidance Model

The persona engine returns a structured guidance object with:

- the communication dimensions
- ordered communication rules
- metadata for traceability

No prose is generated by this layer.

---

## 5. Prompt Builder Integration

The prompt builder consumes:

- `UnifiedCoachIntelligence`
- `CoachPersonaGuidance`

The prompt builder remains responsible for prompt assembly and continues to be the only component that renders the final LLM prompt.

---

## 6. Runtime Integration

```txt
Experts
↓
Composition Engine
↓
Unified Coach Intelligence
↓
Coach Persona Engine
↓
Prompt Builder
↓
OpenAI
```

If persona generation fails, the runtime preserves the unified intelligence object, skips persona augmentation, and continues the existing chat flow.

---

## 7. Observability

The persona layer records internal-only signals for:

- persona generation started
- persona generation completed
- selected tone
- selected focus
- selected verbosity
- selected urgency
- selected safety level
- execution duration
