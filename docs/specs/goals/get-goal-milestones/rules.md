# Rules

## Milestone types

- `weight_target`
- `workout_count`
- `streak`
- `adherence`
- `recovery`
- `custom`

## Milestone strategy

- weight loss: 25%, 50%, 75%, 100%
- workout count: 10, 25, 50, 100
- streak: 7, 30, 60, 100
- recovery: readiness above threshold for multiple days

## General rules

- milestones are derived from the current goal
- milestone state must be deterministic
- avoid over-generating milestones
