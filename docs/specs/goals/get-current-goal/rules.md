# Rules

## Canonical goal vocabulary

- `lose_weight`
- `gain_muscle`
- `maintain_weight`
- `improve_consistency`
- `improve_recovery`

## Goal status

- `active`
- `achieved`
- `abandoned`

## General rules

- only one active goal should exist per user
- the current goal is a read model, not a derived guess
- if no active goal exists, the use case should fail explicitly
