# Errors

```txt
AUTH_INVALID_SESSION
USER_PROFILE_NOT_FOUND
FITNESS_PROFILE_NOT_FOUND
NUTRITION_PROFILE_NOT_FOUND
NUTRITION_PLAN_ALREADY_EXISTS
NUTRITION_PLAN_UNSAFE_MEAL_TEMPLATE
NUTRITION_PLAN_INTERNAL_ERROR
```

## HTTP Mapping

```txt
AUTH_INVALID_SESSION -> 401
USER_PROFILE_NOT_FOUND -> 404
FITNESS_PROFILE_NOT_FOUND -> 404
NUTRITION_PROFILE_NOT_FOUND -> 404
NUTRITION_PLAN_ALREADY_EXISTS -> 409
NUTRITION_PLAN_UNSAFE_MEAL_TEMPLATE -> 422
NUTRITION_PLAN_INTERNAL_ERROR -> 500
```

## Notes

- `NUTRITION_PLAN_UNSAFE_MEAL_TEMPLATE` means no available deterministic template can satisfy allergies and restrictions.
- Existing plan conflict can be bypassed only through explicit `replaceExisting`.
