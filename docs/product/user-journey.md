# User Journey — Elev9 Coach

## Overview

This journey reflects the current shipped experience.

## Primary Journey

1. User signs in.
2. User lands on the dashboard or coach briefing path depending on the app entry point.
3. Coach Home shows today's priority, context, actions, and latest coach message.
4. Daily Briefing summarizes the day in coaching language.
5. Ask Coach surfaces contextual questions and routes directly into conversation.
6. Coach Conversation handles contextual chat and preserves draft/history.
7. Coach Insights explains why a recommendation exists.
8. Coach Memory Timeline shows meaningful memories and behavior patterns.
9. Weekly Review summarizes the week, wins, opportunities, and next focus.
10. Goal Guidance explains progress toward the active goal.
11. Smart Notifications surface timely nudges and notification history.

## Common Entry Points

- Dashboard AI Coach card
- Coach tab
- Workout completion
- Nutrition recommendations
- Notifications
- Profile coach links

## Coach Loop

The coach loop now spans:

```txt
Home
→ Briefing
→ Ask Coach
→ Conversation
→ Insights
→ Memory
→ Weekly Review
→ Goal Guidance
→ Notifications
```

## Notes

- The journey is contextual, not chat-first.
- The coach uses existing training, nutrition, recovery, goals, habits, personalization, and notification signals.
